# Output Modes

세 가지 모드는 모두 같은 템플릿을 사용하며, `<html>`의 `data-mode` 속성으로 전환된다.
빌더(`scripts/build_mindmap.py`)의 JSON 스펙에 `"mode"` 키로 지정하면 자동 적용됨.
모든 모드는 루트 `DESIGN.md`의 classroom whiteboard workspace 디자인 계약을 공유한다.
모드별 차이는 크기·밀도·퀴즈 표시 같은 렌더링 차이이며, 브랜드 클론이나 별도 미학을 뜻하지 않는다.

`mode`는 화면 렌더링 방식만 정한다. 수업 목적은 `pedagogy.lesson_purpose` 또는 작성 메모에서
`도입`, `정리`, `복습`, `평가`, `탐구`로 별도 관리한다. 예를 들어 `lesson_purpose=정리`인
마인드맵도 화면 공유용이면 `mode=발표용`이 될 수 있고, 자기 점검 활동이어도 퀴즈가 승인되지
않았다면 `mode=교과용`으로 유지한다.

| 모드 | `data-mode` 값 | 선택 기준 |
|------|---------------|----------|
| 교과용 | `교과용` (기본) | 사용자가 모드를 말하지 않으면 항상 이것 |
| 발표용 | `발표용` | 화면 공유·교실 발표 등 시각 강조를 원할 때 |
| 퀴즈형 | `퀴즈형` | 사용자가 퀴즈 요소를 명시적으로 승인했을 때만 |

## 수업 목적과 조합

- `도입`: 흥미 질문, 생활 연결, 선지식 확인을 중심으로 브랜치를 잡는다.
- `정리`: 핵심 개념, 관계 묶기, 한 문장 요약, 남은 질문을 중심으로 잡는다.
- `복습`: 이전 차시 기억 깨우기, 빈칸 확인, 오류 고치기, 재적용을 중심으로 잡는다.
- `평가`: 확인 질문, 수행 과제, 판단 근거, 자기 점검을 중심으로 잡는다.
- `탐구`: 탐구 문제, 가설/예상, 방법, 자료 정리, 해석, 확장 질문을 중심으로 잡는다.

세부 브랜치 기본값은 [branch-archetypes.md](branch-archetypes.md)를 참고한다. 수업 목적은
브랜치 내용과 `pedagogy` 패널에 반영하고, 모드명(`교과용`, `발표용`, `퀴즈형`)을 새로 만들지 않는다.

## 교과용 (기본)

수업 자료, 개념 정리, 학생용 복습 자료.

- 차분한 색, 명확한 위계, 짧은 라벨, 읽기 쉬운 불릿
- 클릭 expand/collapse만 (애니메이션·퀴즈는 승인 전 금지)
- 템플릿 기본값 그대로 — 별도 조정 불필요
- 기본 화이트보드 디자인 토큰은 `DESIGN.md`를 따른다.

## 발표용

교실 발표, 연수 발표, 화면 공유. `data-mode="발표용"` 설정만으로 아래 정량 스펙이 CSS·JS에서 자동 적용된다 (수치를 직접 수정하지 말 것):

| 항목 | 교과용 | 발표용 |
|------|--------|--------|
| 페이지 제목 h1 | 34px | 42px |
| 중앙 원 | 320px | 380px |
| 중앙 제목 h2 | 38px | 46px |
| 브랜치 노드 너비 | 260px | 280px |
| 브랜치 제목 | 21px | 23px |
| 세로 간격(middleGap) | 54px | 80px |
| 본문 텍스트 색 | #24322d | #1c2925 (대비 강화) |

콘텐츠 작성 규칙:

- 브랜치당 불릿 **최대 3개**, 각 불릿 한 줄
- staged reveal(단계 공개)은 애니메이션이므로 승인 후에만

## 퀴즈형

복습 활동, 자기 점검, 수업 마무리 확인. **사용자가 퀴즈 요소를 명시적으로 승인한 경우에만 사용.**

- 마인드맵 구조는 그대로 유지
- 브랜치 `content` 안에 퀴즈 블록 추가 — 템플릿에 CSS·JS 내장:

```html
<div class="quiz">
  <p class="quiz-q"><i class="bi bi-question-circle"></i> 질문 텍스트</p>
  <button type="button" class="quiz-toggle" aria-label="브랜치 제목 정답 보기">정답 보기</button>
  <p class="quiz-a hidden">정답 텍스트</p>
</div>
```

- 빌더 사용 시: 브랜치에 `"quiz": {"q": "...", "a": "..."}` 추가하면 위 마크업 자동 생성
- 모든 브랜치에 퀴즈를 넣을 필요 없음 — 점검 가치가 있는 브랜치에만
- 타이머·점수 시스템·게임 효과는 별도 요청 없이는 금지
